# Retra extension repository

Catalog extensions for Retra (extension API 1). Add this URL in Retra under **Browse → Extensions → ⋮ → Extension repos → Add**:

```
https://raw.githubusercontent.com/Layfate/Retra/main/extensions/index.json
```

## Extensions

- **PokéHarbor · PokeMundo · Roms Games**: Website-named sources with searchable ROM hacks, official GB/GBC/GBA releases and cover images.

Update the former Romhack Plaza extension to version 3.0 to get these sources. The default index contains one extension; the two homebrew extensions are omitted.

Search the installed catalogs in Retra. Use Download on website on a game, or Search website in the source menu, to browse the original site inside Retra. Supported ROM, ZIP and patch downloads can be imported into Library. Patches require your own compatible base ROM. Website downloads require the updated Retra app; older apps can still browse the catalogs.

Official games come from the No-Intro release lists in libretro-database, with available box art from libretro-thumbnails. Roms Games entries open a title search, so availability depends on the website. Hack titles and covers come from the public WordPress APIs. Catalogs refresh weekly; the in-app website search can find newer entries. Files are not re-hosted, and commercial downloads are not labeled as openly licensed.

These files are generated by `tools/extension-repo/build-repo.cjs` in `extensions/` on `main` and refreshed weekly. Do not edit them by hand.
