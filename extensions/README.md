# Retra extension repository

Catalog extensions for Retra (extension API 1). Add this URL in Retra under **Browse → Extensions → ⋮ → Extension repos → Add**:

```
https://raw.githubusercontent.com/Layfate/Retra/main/extensions/index.json
```

## Extensions

- **Retra Sources**: Roms Games, PokéHarbor, Romhacking.net, Hackdex and Operation iDroid: searchable GB/GBC/GBA catalogs with cover art, plus in-app website search and downloads into Library.

Retra Sources 4.0 replaces the former Romhack Plaza extension and updates it in place. The default index contains one extension; the two homebrew extensions are omitted.

## Sources

| Source | Platforms | In Retra |
|---|---|---|
| Roms Games | GB, GBC, GBA | Official releases (No-Intro) with box art; each game opens a Roms Games title search |
| PokéHarbor | GBC, GBA | Hack catalog from its public WordPress API, with artwork |
| Operation iDroid | GBC, GBA | Hack catalog from its sitemap and page data, with artwork; NDS hacks are skipped |
| Romhacking.net | GB, GBC, GBA | Website source: search and download in the in-app browser |
| Hackdex | GB, GBC, GBA | Website source: browse and download in the in-app browser |

Romhacking.net and Hackdex protect their pages with a bot check, so the builder cannot list their games. Open them from the source page; Retra shows the site in its in-app browser, where you can pass the check, search and download.

Search the installed catalogs in Retra. Use Download on website on a game, or Search website in the source menu, to browse the original site inside Retra. Supported GB, GBC, GBA, ZIP, IPS, UPS and BPS downloads are imported into Library. Patches require your own compatible base ROM. Website downloads require the updated Retra app; older apps can still browse the catalogs.

Official games come from the No-Intro release lists in libretro-database, with available box art from libretro-thumbnails. Roms Games entries open a title search, so availability depends on the website. Catalogs refresh weekly; the in-app website search can find newer entries. Files are not re-hosted, and commercial downloads are not labeled as openly licensed.

These files are generated by `tools/extension-repo/build-repo.cjs` in `extensions/` on `main` and refreshed weekly. Do not edit them by hand.
