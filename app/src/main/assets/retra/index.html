Privacy Policy

Retra Privacy Policy

Effective for Retra v1.0.0

Local game data. Retra stores your library metadata, settings, save files, save states, cheats, controller layouts, artwork preferences, and play statistics on your device. Retra does not include ROMs or copyrighted game software.

Network features. Internet access is used for features such as automatic artwork lookup, optional Google Drive synchronization, Wi-Fi Remote Link, and the lightweight GitHub Releases update check. Update checks contact Retra's official GitHub repository and do not include your ROMs, saves, or library contents. Bluetooth access is used only for Bluetooth Remote Link.

Google Drive. If you enable automatic Drive backup or explicitly choose Restore from Google Drive, Retra uses the authorization granted by you to synchronize supported saves, save states, library metadata, statistics, and portable settings with your own Drive storage. ROM and BIOS files are not uploaded. Drive backup can be disabled at any time.

No advertising or analytics SDK. This build does not include an advertising SDK or a third-party analytics SDK.

Permissions. Retra requests device or network permissions only when needed for enabled features. You can revoke Android permissions from system settings.

Data deletion. Removing a game from the Library is non-destructive by design. Use Retra's explicit Delete Game Data action when you want associated local game data removed.

Uninstall and reinstall. Retra participates in Android backup/device transfer and asks supported Android versions to offer a Keep app data option during uninstall. Android still controls whether retained or cloud-backed data is available after reinstall, so a portable .retra backup remains the safest explicit recovery copy.

Policy updates. If Retra's data practices change, this policy should be updated before publishing the changed build.
